# OpenBrainSkill 睡眠分期 MVP：24 天代码开发版计划

版本：2026-07-13 v3  
工作强度：5 人，每人每天 1 小时，连续 24 天  
核心原则：少写空泛报告，多写代码、多跑命令、多保存执行结果。必要文档只服务于复现和答辩，不把文稿当主要产物。

---

## 1. 新分工

现在团队拆成两条开发线：

```text
A 线：Agent / LLM / OpenBrainSkill 封装
  林容增 + 张瑞涵

B 线：NeuroSkill 调度 / EDF-LSL / 数据接入
  郑博文 + 沈博昊 + 张驰
```

A 线：Agent / LLM / OpenBrainSkill 封装
负责人：林容增、张瑞涵

目标：
把用户的一句话，变成一个可以自动执行的睡眠分期任务。

例如用户说：
“请对 SC4002E0 做睡眠分期并生成报告。”

A 线要做的是：
1. 解析这句话，得到数据文件、任务类型、后端工具、输出要求。
2. 生成执行计划，例如 check_edf -> stream_lsl -> neuroskill_sleep -> evaluate -> report。
3. 调用 B 线写好的工具脚本。
4. 根据每一步结果判断下一步。
5. 如果 NeuroSkill 失败，给出失败诊断或切换备用路线。
6. 根据真实 JSON/CSV 结果生成自然语言报告。



B 线：NeuroSkill 调度 / EDF-LSL / 数据接入
负责人：郑博文、沈博昊、张驰

目标：
把真实脑电数据变成 Agent 可以调用的工具。

B 线要做的是：
1. 用 MNE 读取 Sleep-EDF 的 PSG 和 Hypnogram。
2. 把 EDF 数据转换成 LSL 虚拟实时流。
3. 让 NeuroSkill 能发现、连接并记录这个 LSL 流。
4. 调用 NeuroSkill sleep 命令拿到分期结果。
5. 如果 NeuroSkill 失败，返回明确错误 JSON，而不是只说“失败了”。
6. 提供真实标签、预测标签和评估输入。





两条线每天都要产出代码、JSON、日志、截图或可运行结果。文档只保留三类：

1. 运行说明。
2. 接口说明。
3. 实验结果记录。

不再安排“写理论长文”“准备答辩问题”“单独写大段报告”这类任务。

## 2. MVP 的真实目标

最终系统不是单纯的数据处理脚本，而是一个带 Agent 调度能力的睡眠分期 skill：

```text
用户自然语言请求
  -> SleepStagingAgent 解析任务
  -> 生成结构化执行计划
  -> 调用 MNE 数据检查工具
  -> 调用 EDF->LSL 推流工具
  -> 调用 NeuroSkill 发现/连接/session/sleep
  -> 调用评估脚本
  -> LLM/规则报告生成器输出自然语言报告
```

注意：LLM 不直接判断睡眠阶段。  
LLM/Agent 的价值是调度工具、诊断错误、生成解释。

### 每日 1 小时工作格式

每个人每天都按这个节奏做，不要把 1 小时花成“看资料但没有产物”：

